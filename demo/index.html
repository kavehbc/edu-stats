Academic Statistics Parser

Edu-Stats

Fetch citation counts, h-index and i10-index from Google Scholar, Scopus and Publons, and use them on any website as JavaScript variables or JSON.

Documentation & source on GitHub

Try it

Enter at least one profile ID, then retrieve the data.

JavaScript variables

With the JavaScript output, once the script is included each item is stored in its own global variable, accessible from your page.

JSON output

Setting output=json returns JSON, suitable for parsing and AJAX calls. The response for the request above:

n/a

Usage

For instance, to print the Google Scholar h-index on a page, include the script and write its variable:

<script src="/query/?google=7ftCdTQAAAAJ"></script>
<script>document.write(Google_hIndex);</script>
